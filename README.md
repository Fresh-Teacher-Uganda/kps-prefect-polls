# KPS Prefect Polls

I would like to build a voting app for Kyengera Parents School (KPS - Action Not Words) prefect elections.

Use the electoral logic and flows from the attached code (candidate application, candidate list, ballot voting, live results, application status).

Style the entire UI using the attached reference screenshots:
- Deep purple/navy gradient background (#120826 to #1D0B3B) with warm amber/gold accents (#F59E0B) and borders
- Mobile-first candidate directory cards with photos, candidate names, school/class badges, position categories, and gold vote counts
- Candidate details view with profile picture, stats bar (votes, class, age/photos), vote button, and manifesto/about tabs
- Modern bottom-sheet style vote confirmation and success modal
- Include the Kyengera Parents School crest and motto 'Action Not Words' in the branding
